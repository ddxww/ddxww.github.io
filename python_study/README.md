# Python 学习路径

这里整理了我在 PyCharm 中完成的 Python 学习代码。代码按学习方向分为以下几部分：

## 人工智能学习路径

1. **机器学习**：从 KNN、梯度下降、特征处理开始，逐步学习逻辑回归、决策树、随机森林、聚类和降维等方法。
2. **深度学习**：学习 NumPy 神经网络、反向传播、优化器和卷积神经网络，并完成手写数字识别、Fashion-MNIST 服装识别等实践。
3. **自然语言处理**：学习文本特征、RNN、LSTM、GRU、Attention 和 Transformer，并完成文本分类和中英翻译实践。

## 其他 Python 练习

`基础练习` 文件夹收录了数据分析、数学建模、算法和 Python 语法等练习代码。

项目中的数据集、模型权重、虚拟环境和缓存文件没有上传；运行代码时需要根据文件中的导入内容自行准备依赖和数据。
