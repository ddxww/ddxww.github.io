## Python 与人工智能学习代码

学习代码统一整理在 [`python_study`](./python_study/) 目录中：

```text
python_study/
├── 人工智能学习路径/
│   ├── 01_机器学习/
│   ├── 02_深度学习/
│   └── 03_NLP/

```

仓库仅保留源代码和少量 Notebook，不包含虚拟环境、大型数据集、模型权重和缓存文件。部分代码需要自行准备依赖与数据后运行。
